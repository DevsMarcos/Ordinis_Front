# Ordinis — Front-end

Este repositório contém a parte **front-end** de um projeto full stack para gestão de ordens de serviço, desenvolvido em **React Native (Expo)**.

## Sobre o projeto

Este é um projeto **100% experimental**, com o objetivo principal de aprender e aplicar na prática conceitos importantes de **desenvolvimento mobile** — navegação, formulários, consumo de API, gerenciamento de estado, arquitetura de componentes, entre outros.

O front-end aqui presente se integra a um **back-end** que também está em desenvolvimento, formando juntos uma aplicação full stack para cadastro, consulta e acompanhamento de ordens de serviço.

## Tecnologias

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/) / Expo Router
- [TypeScript](https://www.typescriptlang.org/)
- [React Hook Form](https://react-hook-form.com/)
- [Zod](https://zod.dev/) para validação de schemas
- [Axios](https://axios-http.com/) para consumo da API

## Objetivos de aprendizado

- Navegação com rotas dinâmicas e grupos de rotas (Expo Router)
- Construção e validação de formulários
- Consumo de API REST e tratamento de estados de carregamento/erro
- Organização de componentes reutilizáveis e camadas de serviço
- Boas práticas de UI/UX em aplicações mobile (Android/iOS)

## Status

🚧 Em desenvolvimento ativo — tanto o front-end quanto o back-end estão sendo construídos e evoluídos em paralelo.
